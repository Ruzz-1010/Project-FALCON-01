What changed vs V2

  • Squat drum hull Ø1.2m, rounded bilge, bolted deck rim — instead of Ø650mm body + keel
  • Tapered 4-sided tower one solar panel per sloped face, ~40W class total — instead of dual 30W array
  • Red topmark beacon + whip per reference buoy; deck hatch for the ESP32 stack
  • Light single-point mooring eyes + chain stub

Sensor placement fixes (from review)

  • Rotor on a slim Ø36mm mast hub straight on the pole — no fat tube in the rotor plane
  • 3 open cups Ø130mm, Ø600mm spacing was 200mm / Ø880mm
  • Wind vane 150mm below rotor speed + direction
  • GPS dome = true hemisphere phi 2π · theta π/2
  • LoRa case visible on clamp band not hidden behind lug; whip offset below rotor plane
