Main Lite concept updated to the compact reference-style buoy with cloud-first, event-driven telemetry.

What changed for DOST

  • One compact cylindrical float simple can-buoy form, fewer fabricated parts
  • Tapered top housing keeps electronics high and gives solar-panel faces
  • Small side solar panels paired with smaller 6-10Ah LiFePO4 target
  • Direct cloud telemetry ESP32 Wi-Fi for near-shore tests, LTE module for field trials
  • No LoRa gateway in the reduced baseline shore station becomes optional future expansion

Event-driven behavior

  • Normal sea motion is filtered small waves do not trigger spam
  • Send on meaningful change pressure jump, tilt/impact, drift, low battery, tamper
  • Slow heartbeat remains example: every 5-15 minutes so the system knows it is alive
  • Offline buffering save events locally, upload when signal returns

Sensor / electronics placement

  • Pressure sensor in side stilling tube reduces wave slap and protects the sensor
  • ESP32 + power board inside tapered sealed housing short wiring, easier service
  • LTE/Wi-Fi antenna above the cap kept clear of splash zone
  • IMU inside the tube detects tilt, impact, and movement events
  • GPS puck on top cap optional when drift/location is required
