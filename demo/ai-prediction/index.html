What the model is doing

The buoy never “sees” a wave. It estimates wave height from underwater pressure variations, and the model fits a short trend on the recent history, then projects it forward with damping and a change limit.

  1. Validate the newest wave-height samples
  2. Fit a linear trend over the last 120 samples (4 min)
  3. Project that trend to the selected horizon
  4. Dampen the movement (longer horizon → stronger damping)
  5. Clamp implausible jumps (short presentation window)
  6. Classify CALM / MODERATE / ROUGH and report confidence from residual volatility
