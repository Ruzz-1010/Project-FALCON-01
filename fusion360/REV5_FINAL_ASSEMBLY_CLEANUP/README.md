# REV5_FINAL_ASSEMBLY_CLEANUP

Applies a reversible visibility-only cleanup for the Revision 5 assembly. It
hides superseded stabilizers, old electronics/cooling hardware, earlier solar
and frame revisions, and fixed ballast. It shows the current traditional body,
two-panel frame/array, sealed pod systems, adjustable ballast, and anchor.

No component is moved, edited, or deleted. Missing active components are listed
after the script runs so the export is not mistaken for a verified assembly.
