# REV5_FINAL_ASSEMBLY_CLEANUP

Applies a reversible visibility-only cleanup matching the 20 top-level systems
in `exports/PROJECT FALCON -V2.fbx`. It hides superseded stabilizers, old
electronics/cooling hardware, earlier solar and frame revisions, and shows the
finalized V2 float, two-panel solar array, sealed thermal/electronics systems,
structural frame, pressure sensor, ballast, and mooring systems.

No component is moved, edited, or deleted. Missing active components are listed
after the script runs so the export is not mistaken for a verified assembly.
