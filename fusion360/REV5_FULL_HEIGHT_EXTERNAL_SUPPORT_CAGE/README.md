# REV5_FULL_HEIGHT_EXTERNAL_SUPPORT_CAGE

Creates the continuous external metal structure shown by the selected upper and
lower body rings: four long tubes run from the upper mast/deck region down the
outside of the main float to a new EPDM-lined lower structural collar.

The selected blue HDPE lower fairing is not used as the load-bearing member.
The new 6061-T6 split-collar envelope surrounds it with an isolation liner, so
mast wind loads bypass the plastic shell and enter the lower structure.

The earlier short `REV5_UPPER_TO_LOWER_LOAD_CAGE` is hidden, never deleted.
Verify clamp pressure, buoy-shell creep, hydrodynamic drag, fatigue, corrosion,
welds/fasteners, righting moment and flotation before fabrication.
