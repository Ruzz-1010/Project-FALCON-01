# REV5_FULL_HEIGHT_EXTERNAL_SUPPORT_CAGE_V2

Corrects the V1 upper connection. Each of the four load paths now starts at a
top mast corner, slopes outward to the upper buoy-frame ring, then continues
vertically outside the main float to the EPDM-lined lower structural collar.

The tubes no longer terminate at or connect only to the mast feet. V1 is hidden
after successful generation, not deleted. Existing components are not moved,
cut, joined, or deleted.
