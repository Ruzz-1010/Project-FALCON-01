# REV5_UPPER_TO_LOWER_LOAD_CAGE

Adds a separate four-leg metal load-transfer cage between the tapered mast feet
and the existing lower split-clamp frame. It does not cut, move, join, or delete
any completed component.

Four 32 mm 6061-T6 primary struts carry upper wind and equipment loads to the
lower frame. Eight 20 mm knee braces resist racking. EPDM isolation pads and
316L fastener attributes are included for the dissimilar-material interfaces.

This is design geometry. Verify global stability, local stresses, fatigue,
fasteners, HDPE clamp pressure, corrosion isolation, and wave/wind cases before
fabrication.
