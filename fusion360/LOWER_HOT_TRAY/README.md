# LOWER_HOT_TRAY Fusion 360 Script

Creates a separate removable lower tray inside `ELECTRONICS_BOX`. A 220 mm-high
HDPE thermal divider isolates the battery from the mini-PC/MPPT/DC-DC bay. The
hot-electronics side is reserved for an isolated 80 mm intake/exhaust cross-flow
path; fan and duct hardware remain separate serviceable components.
