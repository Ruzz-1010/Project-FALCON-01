# SOLAR_PANEL_ELEVATION_UPGRADE

Raises only the four existing solar-panel occurrences by 150 mm. If the tilt
brackets exist, they are raised by the same amount. Eight 12 mm 6061-T6 struts
extend from the 870 mm upper-frame rail to the new 1,020 mm bracket line.

Capture Position and save before running. Capture Position and save again after
the successful upgrade.
