# REV5_MAIN_BUOY_FRAME_SUPPORT

Creates the missing structural load path from the 650 mm HDPE main buoy to the
Revision 5 upper frame. It includes a lined clamp band, four diagonal risers, an
annular service deck, four isolated frame pads, and eight gusset plates.

Design intent is non-penetrating: do not drill through the sealed HDPE shell.
The circular CAD band represents a fabricated two-half clamp assembly. Verify
clamp pressure, HDPE creep, fasteners, fatigue, cap access, and structural loads
before manufacturing.
