# WATER_PRESSURE_SENSOR_ASSEMBLY

Adds one separate editable component named
`WATER_PRESSURE_SENSOR_ASSEMBLY_REV6_PROPOSED` to the current Fusion assembly.

The proposed location is on the submerged lower shoulder of the main float,
offset from the centerline so the pressure port remains clear of the ballast and
anchor-chain load path. The assembly contains a Bar02-compatible packaging
envelope, downward pressure port, open six-rod protective guard, 316L mounting
plate, and IP68 cable-gland envelope.

This is proposed integration geometry, not an installed or calibrated sensor.
Its radial offset, height, sensor size, and guard dimensions are user parameters.
Final placement requires a waterline check, cable-routing review, and controlled
pressure calibration. Report wave height as **ESTIMATED** and **CALIBRATION
REQUIRED** until validation is complete.

The generator stops before changes when positions are uncaptured or the target
component already exists. It does not move, hide, edit, or delete existing parts.
