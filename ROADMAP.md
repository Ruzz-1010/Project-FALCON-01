# FALCON-01 Roadmap

## Phase 1 — Local controller
- ESP32 setup
- PlatformIO
- Wi-Fi access point
- Captive portal
- Local dashboard
- Basic controls

## Phase 2 — Dashboard foundation
- LittleFS
- Responsive UI
- Live API polling
- Settings and diagnostics
- Error handling

## Phase 3 — Sensors and power
- Water temperature
- IMU
- Battery monitoring
- Solar monitoring
- Calibration

## Phase 4 — GPS and security
- GPS coordinates
- Home position
- Geofence
- Movement and tamper detection
- Alert logs

## Phase 5 — Data logging
- Local history
- CSV/JSON export
- Charts
- Storage management

## Phase 6 — AI
- Collect and label data
- Train sea-condition classifier
- Validate accuracy
- Deploy TinyML or use Raspberry Pi if necessary

## Phase 7 — Remote communication
- LoRa or cellular
- Offline buffering
- Secure transmission

## Phase 8 — Cloud and app
- Backend
- Database
- Accounts
- Notifications
- Multiple-buoy support

## Phase 9 — Marine deployment
- Solar system
- Waterproof enclosure
- Corrosion resistance
- Buoyancy and anchoring
- Coastal field testing
